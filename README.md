# InstaHome Design Builders

> **Architectural Vernacular Modernism · Palayamkottai, Tirunelveli**

A production-quality web application faithfully crafted from the Google Stitch architectural design for **InstaHome Design Builders**, an architecture, interior design, and turnkey build studio based in Palayamkottai, Tirunelveli, Tamil Nadu.

---

## ✨ Key Features

- **Pixel-Accurate Fidelity:** Faithfully reproduces the Google Stitch design tokens, colors (surface cream `#fef9f1`, deep scorched teak `#130e0a`, warm terracotta `#8c4e30`), typography (`Playfair Display` & `Manrope`), and layout composition.
- **Cinematic Responsive Motion:** Subtle, hardware-accelerated micro-interactions, page transitions, and hover effects powered by Framer Motion.
- **Complete Multi-Page Routing:** Seamless navigation between Home, About, Projects, Services, and Contact pages with smooth instant scroll-to-top.
- **Curated Bento Portfolio:** Asymmetric grid showcase of signature commissions with interactive architectural modal drawers.
- **Filterable Archive:** Category tabs for Residential, Interiors, and Commercial works.
- **5-Stage Process & Materiality Showcase:** Visual manifesto, guiding pillars, and tactile vocabulary breakdown.
- **Interactive Consultation Booking:** Complete inquiry form with validation, status feedback, direct call, WhatsApp integration, and Palayamkottai coordinate map viewport.
- **100% Responsive & Accessible:** Optimized for all screen sizes from mobile (320px–430px) to desktop (1440px+) with zero unwanted horizontal scroll, full keyboard navigation, and reduced-motion support.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Animations:** Framer Motion
- **Routing:** React Router v7
- **Typography & Icons:** Playfair Display, Manrope, Google Material Symbols Outlined

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/risa113/instahome.git

# Navigate into the project directory
cd instahome

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The app will be running at `http://localhost:5173/`.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
